# Análisis del Sistema de Gestión de Refugio Animal

## Actores Principales
| Actor | Descripción |
|---|---|
| **Ciudadano / Reportante** | Reporta animales en situación de riesgo, indica ubicación y condición |
| **Voluntario / Veterinario** | Recibe el caso, atiende al animal, registra avances y tratamientos |
| **Administrador del Refugio** | Valida expedientes, asigna responsables, aprueba adopciones y cierra casos |

## Requerimientos Funcionales
- RF-01: Crear expediente de rescate con datos del animal
- RF-02: Categorizar por especie: Perro, Gato, Fauna Silvestre
- RF-03: Asignar voluntario o veterinario responsable

## Requerimientos No Funcionales
- RNF-01: **Escalabilidad** — Agregar nuevas especies sin reescribir código
- RNF-02: **Mantenibilidad** — Código modular y bien documentado
- RNF-03: **Trazabilidad** — Todo cambio registrado con Gitflow
